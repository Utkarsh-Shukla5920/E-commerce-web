# Prime-Web 🛍️

Prime-Web is a simple online shopping website I made using HTML and CSS. I wanted to create a website where people can browse different products, check their prices, and explore a few shopping categories.

## About the Project

This is a front-end project with separate pages for the home page, products, about us, and contact. I added product images, prices, star ratings, and a special offer section to make the website feel more like an online store.

## Pages

- **Home:** Introduction, featured products, latest products, and a special offer.
- **Products:** A collection of products with their prices and ratings.
- **About Us:** A short introduction to the website and its purpose.
- **Contact Us:** Contact details and a form to send a message.

## Built With

- HTML
- CSS

## What I Learned

While making this project, I practised connecting multiple HTML pages, styling layouts with CSS, adding images, and using Flexbox to arrange products. I also worked on making the website easier to navigate.

## Future Improvements

I would like to make the website more mobile-friendly and add features like product search, a working cart, and better product filtering in the future.
